# Bobby promo film v2 — motion graphics (Seedance 2.5)

**Date:** 2026-09-03 · **Owner:** Anthony · **Status:** objective + core message locked; script in progress

Process agreed with Anthony (in order): objective → core message → script → key images → Seedance 2.5 video.
Predecessor: `docs/video/bobby-launch-v1/` (3D CG character film; feedback: it sold features, not benefits).

## 1. Objective (locked 2026-09-03, corrected by Anthony)

**Announce the waitlist to try the Bobby app.** Everything in the film is centred on the app, not
the protocol. The core message is the reason to join; the CTA is the waitlist itself.

- Deliverable of the film: sign-ups at `bobbyprotocol.xyz/app#early-access` (the "Join early access"
  form on the app landing).
- Secondary: make someone who already asks ChatGPT about their assets understand, in ~15 seconds,
  that Bobby checks the market before it answers.

- Audience: Gen Z / millennial who already asks an AI about BTC, NVDA, gold. Not a pro trader.
- Shift: from "another crypto AI app" to "the one that checks before it answers".
- Language: ENGLISH (Anthony, 2026-09-03: the audience is English-speaking). On-screen text and both voice lines in EN.
- Formats: 9:16 for Instagram, 16:9 for Twitter/X and LinkedIn. Storyboard and video in 9:16 first, then a 16:9 restage of the approved frames.
- Protagonist: same features as Element char_cdmx but ~21 years old (Gen Z), generated as a new Element `char_cdmx_young` from a 2x2 reference sheet.
- ~15 s, no voice-over, music + sound design, on-screen text.
- Never promises returns. It is allowed to show a "no trade" answer.
- End frame must carry the waitlist CTA and the URL, not "coming soon".

## 2. Core message (locked 2026-09-03, after 8 iterations with Anthony)

```
ES:  ChatGPT te responde. Bobby comprueba el mercado antes de responder.
EN:  ChatGPT answers. Bobby checks the market first.
```

Why this line won:
- Says the market (otherwise Bobby reads as a generic chatbot).
- Says the order (Bobby also answers, but after checking).
- No protocol words: no verdict / debate / refuted / record / on-chain / agents.
- Flows like speech, not like three slogans stapled together (Anthony's feedback on earlier drafts).

Discarded on the way: "veredicto desafiado + registro antes del resultado" (too technical),
"ChatGPT nunca te va a decir que no" (ChatGPT does put generic risk disclaimers; attackable),
"Bobby pone a prueba el mercado" (Bobby tests the answer, not the market).
